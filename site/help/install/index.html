Help / Installation

Install your new workspace.

Choose your computer, check the download, and open XailonHub. You don’t need Go, Rust or Node.js to run the app.

Public preview

These builds are not Apple-notarized or Windows publisher-signed. Download only from this portal or our linked GitHub release repository. Checksums detect corruption; they are not a publisher signature.

1. Choose the right download

macOS

Open Apple menu → About This Mac. If you see “Chip” with an Apple M-series name, choose Apple Silicon. If you see an Intel processor, choose Intel. macOS 12 or later is required.

Open the DMG and drag XailonHub into Applications. Open it from Applications. If Gatekeeper blocks this preview, review the warning and source in System Settings → Privacy & Security. Only use the app-specific “Open Anyway” option if you trust this build. Do not disable Gatekeeper globally.

Windows

Open Settings → System → About → System type. Snapdragon computers normally use ARM64; Intel and AMD computers normally use x64. Download the matching setup.exe and follow the per-user installer. The installer includes the offline Microsoft WebView2 runtime needed by the app.

Windows may show an unknown-publisher or SmartScreen warning because this preview is not publisher-signed. Check the source and checksum before deciding whether to proceed. Managed devices may require your administrator’s approval.

Linux

Use the .deb package on Ubuntu 24.04+ or a compatible Debian-based system. ARM64 covers aarch64 machines; x64 covers amd64 machines. Check your processor with uname -m. Install with sudo apt install ./XailonHub_0.3.3_linux_arm64.deb, substituting your downloaded filename. The package manager installs the required WebKitGTK system libraries.

RPM packages are also provided for compatible distributions with WebKitGTK 4.1 and GTK 3. Install the downloaded RPM through your package manager. Distribution-specific runtime testing is still limited.

2. Verify your download

Compare its SHA-256 value with checksums.txt from the same release. On macOS run shasum -a 256 <downloaded-file>; on Linux use sha256sum <downloaded-file>; on Windows PowerShell use Get-FileHash <downloaded-file> -Algorithm SHA256. Do not install if the values differ.

3. Open the app and finish setup

  1. Allow local networking when asked

    XailonHub needs local-network access to discover and connect your computers. On macOS, check System Settings → Privacy & Security → Local Network. On Windows, allow the Hub on your trusted private network when Windows Firewall asks. You do not need to expose it to the public internet.

  2. Choose a workspace

    Follow the welcome screens to create a Hub or join an existing one. You can start with one computer and add others later.

  3. Connect an AI engine

    The app includes the Hub and interface. AI engines and model weights are separate. Add an engine you already run, or pair a computer that has one.

Where is the admin console?

Open Settings inside XailonHub. On macOS, you can also press ⌘,. The desktop edition intentionally does not expose its admin console at localhost:4747; that address serves the inference API only.

Already running the command-line Hub?

Stop the existing instance before opening the desktop app, or its ports may already be in use. To preserve pairing, back up and move its complete state directory with the configuration. Update node.data_dir to the new location. Do not run two copies with the same identity.

Where does the app store data?

macOS: ~/Library/Application Support/ai.infinialabs.xailonhub.desktop/
Windows: %LOCALAPPDATA%\ai.infinialabs.xailonhub.desktop\
Linux: ~/.local/share/ai.infinialabs.xailonhub.desktop/ (or your configured XDG data location).

The folder contains configuration, pairing state and local logs. Keep backups private. Removing the app does not remove this data. Closing the app stops its Hub; independently running AI engines stay running.

Command-line and server installation

The CLI edition uses a browser dashboard and can run as a background service. These commands install the CLI, not the desktop app. Read the scripts before running them.

macOS and Linux

curl -fsSL https://xailonhub.infinialabs.ai/install.sh | sh

Windows PowerShell

irm https://xailonhub.infinialabs.ai/install.ps1 | iex

For a server, use the shell installer with sh -s -- --hub, or the PowerShell installer with -Hub. For installation without a background service, use --no-service or -NoStartup. The installers verify release checksums.
