Help / Get started

Connect another computer

Pair a Mac, Windows laptop or desktop with a short code.

Before you start

Run XailonHub on both computers and connect them to the same local network. Keep the Hub’s pairing window open while joining.

  1. Get a code on the existing Hub

    Open My devices → Add a device, or use Connect a device on Home. The pairing window shows a six-digit code, its remaining time and the Hub address.

  2. Open setup on the new computer

    Open the XailonHub app on the computer you want to add. Command-line edition users open http://localhost:4747 on that computer instead. Choose Join an existing Hub. If setup is already complete, open Settings → Run setup again first.

  3. Name the new computer

    Continue through the hardware screen, give the computer a recognizable name, and select any local AI engines to share. It can join without an engine and use models shared by other devices.

  4. Find the existing Hub

    On Join a hub, choose your Hub from the nearby list. If it is missing, use Scan again or type the Hub address shown in the pairing window, including port 4748. Do not use localhost for the other computer.

  5. Enter the code and join

    Enter all six digits from the existing Hub, select Review, check the destination, then select Join hub. If the code expired, close the old pairing window and open Add a device again for a fresh code.

  6. Verify both sides

    Open My devices on both computers. Each should show both devices as online within a few seconds. Home lets you select a device and open View device for its hardware details.

You’re done when…

The new computer appears online in the same workspace on both dashboards.

A PIN is short-lived and single-use. Close pairing when finished. Add by address is for a device that already shares your cluster key; it does not replace first-time pairing. Keep invite codes private because they contain the cluster key.
