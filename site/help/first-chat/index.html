Help / Everyday use

Get your first answer

Choose a model, ask a question and see which device answers.

Before you start

At least one healthy engine or configured cloud provider must advertise the model you want.

  1. Choose a model

    Open AI studio. Under Start a conversation, pick a model from the Model list. Models across your hub shows which devices offer each model.

  2. Choose where it runs

    Leave Run on set to Best available for automatic routing. Choose This device only for the current computer, My devices only for paired peers, or Cloud only for your configured cloud provider. A restricted choice fails if that destination has no suitable model.

  3. Set privacy for this request

    Turn on Private: never send to the cloud when the prompt must stay on your devices. Do not combine this with Cloud only; those choices conflict. Private excludes cloud inference, but paired devices still receive the prompt.

  4. Write a prompt

    Type a clear request into What’s on your mind? You can also choose Explain something, Find inspiration or Plan my day to fill in an example. Include the context and output you want.

  5. Send and watch the answer

    Select Send. Text appears as it arrives. The Ran on label identifies the actual device and engine; the timing chip shows time to the first token. Some engines also return reasoning text, which the studio currently displays inline.

  6. Inspect or try again

    Open Activity to check the model, destination and result. Return to AI studio to change the question or model. The studio sends each prompt as a new request; it does not preserve a multi-turn conversation history.

You’re done when…

An answer appears and Ran on identifies the device or cloud provider that served it.

If there is no answer, check the No models or no answer troubleshooting guide. Loaded models usually start faster; a model’s first request may take longer.
