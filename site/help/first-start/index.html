Set up your first Hub

Turn one computer into a shared AI workspace.

Before you start

Have XailonHub installed and keep this computer awake. To share AI, at least one computer needs a running AI engine with a model.

  1. Open your dashboard

    In the desktop edition, open XailonHub from Applications or the Start menu. The app starts its bundled Hub and opens the workspace without a browser. Keep the app open while using it. In the command-line edition, open http://localhost:4747 in a browser; if using a standalone binary, run ./xailon-hub serve --open (Windows: .\xailon-hub.exe serve --open) from its folder first.

  2. Choose a role

    In the first-run wizard, select Make this the Hub for the computer that will coordinate your devices. Choose Just this computer for a solo workspace. Choose Join an existing Hub only when another Hub is already set up.

  3. Give it a familiar name

    Continue to the hardware screen. Check the detected processor and memory, then name the computer something recognizable, such as Studio Mac. Continue to AI engines.

  4. Choose the AI apps to share

    Start your existing AI engine and use Scan again. Select the apps you want to share. If there are none yet, you can continue and add one later in AI studio. XailonHub connects to engines; it does not download a model for you.

  5. Review optional connections

    On the cloud screen, leave the API key empty to skip cloud backup. Enable network app access only if you want other apps or phones to connect directly. Paired Hub devices do not need this switch.

  6. Finish and check Home

    Review the name, role and engines, then select Finish setup. Home shows the network map. Open AI studio to check for available models. You can reopen the wizard from Settings → Run setup again.

You’re done when…

Home opens with your computer in the map. A model appears in AI studio once a connected engine advertises one.

Already set up? Run setup again can change your configuration. Review every choice before finishing; it is not a reset button.
