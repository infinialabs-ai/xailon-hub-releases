Set privacy and connect other apps

Control cloud backup and give another app your Hub address.

Before you start

Know whether the app is on this computer or another device. Keep API keys private.

  1. Choose whether to use cloud backup

    Open Settings → Cloud backup. To enable it, enter the provider’s supported Base URL and API key, switch on Use the cloud when needed, and select Save cloud settings. To disable it, switch it off and save. Wait for Live after any restart.

  2. Keep individual chats on your devices

    In AI studio, turn on Private: never send to the cloud for each request that needs it. Best available may use cloud when allowed; private requests cannot. Local-only routing fails when no suitable local or peer model is available.

  3. Connect an app on this computer

    In Settings → Connect your apps, copy the Base URL into the app’s OpenAI-compatible provider settings. Select a model advertised by this Hub. Use your configured inference key if authentication is enabled; otherwise an app that requires a nonempty key can use local.

  4. Connect an app on another computer or phone

    On the serving Hub, enable Settings → Phones and apps on your network → Allow LAN access. Wait for it to restart, then use http://YOUR-HUB-IP:4747/v1 and the displayed access key in the other app. Replace YOUR-HUB-IP with the Hub computer’s real LAN address; localhost on a phone points to the phone.

  5. Check the result

    Send a short request from that app and check Activity on the serving Hub. Keep Allow LAN access off if only this computer and paired Hubs need access. Pairing and LAN app access are separate features.

You’re done when…

Your app can list a Hub model and receive an answer using the intended local or cloud policy.

The LAN access key permits inference, not dashboard administration. Never put keys in screenshots or public messages. Private means no cloud inference; it is not a promise that a separate engine or app never logs data. In the desktop edition, the window uses a private admin address. Always copy the Base URL from Connect your apps; do not copy the window’s private session address. Port 4747 serves inference only while the desktop app owns the Hub.
