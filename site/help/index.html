Common questions.

What is the difference between a Hub, an engine and a model?

The Hub connects devices and routes requests. An engine is an app that runs AI, such as an OpenAI-compatible local server. A model is the AI loaded or offered by that engine. An assistant is an agent that uses AI to carry out tasks.

Can I use the Hub without cloud access?

Yes. Run a model on this computer or a paired device and leave cloud backup off. Help text and example screenshots are bundled with the app and need no internet connection.

Does My devices only include this computer?

That option selects the cluster tier: other paired devices. Choose This device only for the current computer. Best available with Private enabled can use local and peer engines while excluding cloud inference.

Why do my hardware pictures look different from these screenshots?

The screenshots use an example workspace. Your cards reflect your detected platform and device name. When the exact chassis is unknown, the app uses a representative hardware-family illustration.

Why are there no assistants even though chat works?

Chat needs a healthy AI engine. Assistants also require an installed agent and a configured worker pool. Ask your administrator to configure a pools entry on a device; there is no pool-creation form in the dashboard.

What should I share when asking for help?

Share the Hub version from Settings, your operating systems, the steps you took, the visible error and the model name. Redact API keys, invite codes, pairing codes, private prompts and sensitive addresses before sharing screenshots.
