Run a task with an assistant

Assign work, follow progress and respond to approval requests.

Before you start

An administrator must first install a supported agent and configure a pools entry on at least one device. Adding an AI engine alone does not create an assistant. If you see No pools, finish that setup before continuing.

  1. Choose an assistant

    Open Assistants. Your assistants lists configured workers and how many are busy. In New task, choose the Assistant you want to use.

  2. Choose a device and describe the work

    Leave Device set to Any device to let the Hub choose a free worker, or select a specific device. Enter a concrete task under What should the agent do? State the expected result and any boundaries.

  3. Start the task

    Select Run task. Choose the new entry under Tasks to open its Task timeline. Queued means it is waiting; Working means an agent is running it.

  4. Review requests for permission

    If the task shows Needs approval, read the tool action and device name in the permission card. Select the allow or reject option that matches your intent. Approval options come from the agent; do not approve an action you do not understand.

  5. Check the outcome

    Follow the timeline until Done, Failed or Cancelled. Read the output and verify the result. Use Cancel in an active task’s details if you need it to stop; cancellation does not undo actions already completed.

You’re done when…

The task reaches a final state and its timeline explains what happened.

Workers act on the computer they run on. A Hub restart may interrupt active tasks. The demo workspace has simulated assistants so you can explore without running real work.
