Help / Get started

Connect an AI engine

Make the models in an existing AI app available to your Hub.

Before you start

Install an AI engine, download or load a compatible model in that app, and start its server. Open the Hub dashboard on that same computer.

  1. Find the server address

    In your AI app, locate its local server address and port. Common Hub defaults are Ollama at http://127.0.0.1:11434 and LM Studio at http://127.0.0.1:1234. Use the port actually configured in your app.

  2. Open Connected AI apps

    Go to AI studio, scroll to Connected AI apps, and select Add an engine. This adds an engine to the computer whose dashboard you opened, not to a device selected in the map.

  3. Select the matching engine

    Choose the app under Engine. For a compatible server without its own option, choose OpenAI-compatible. Enter the server’s base address, such as http://127.0.0.1:18092 for an engine running on port 18092. Do not paste a chat-completions endpoint.

  4. Save and allow the Hub to restart

    Select Add engine. The Hub restarts to apply the change, so wait for Live to return. Adding an engine does not install or start the AI app itself.

  5. Check models and try one

    The engine card should report healthy and list models. Choose one in Start a conversation, select This device only, type a short question and select Send. Other paired computers can then use the same model.

You’re done when…

The engine is healthy, its models are listed, and a short prompt produces an answer.

127.0.0.1 means the machine running that Hub. For an engine on another computer, add it from that computer’s Hub and pair the Hubs. An NPU or GPU hardware badge alone does not prove the engine uses that accelerator.
