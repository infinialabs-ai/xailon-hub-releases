Help / Troubleshooting

No models or no answer

Find out whether the engine, model or routing choice needs attention.

Before you start

Open AI studio and identify the model you want to run and the computer that hosts it.

  1. Confirm the engine is running

    On the host computer, open the AI app, load or download the intended model, and start its server. Keep the app running. Hub hardware detection alone does not start inference.

  2. Check the engine address

    In Connected AI apps, check the engine’s health and address. The port must match its server. For a service on port 18092, use http://127.0.0.1:18092 from the Hub on that same computer. If an address is wrong, remove the incorrect engine registration and add it again with the correct address.

  3. Check whether the model is advertised

    Look in Models across your hub. If the model is absent, verify the AI app’s model list and server, then allow the Hub to refresh. A model name from a different provider may not be valid here.

  4. Check your routing restrictions

    Use This device only only when the model exists on this computer; use My devices only when an online peer offers it. Private plus Cloud only cannot succeed. No healthy backend means none of the allowed destinations currently advertises a healthy matching model.

  5. Try a short request

    Select an available model, use a compatible routing choice and ask a short question. The first request may take longer while a model loads. If only reasoning text appears, the engine may be using its output budget before the final answer; check that engine’s thinking and token settings.

  6. Use Activity to narrow it down

    Check the request’s Result and Ran on destination. A successful route does not guarantee that a provider returns useful content. Check the engine’s own logs for model-loading, memory or provider errors if the Hub is reaching it but no usable answer comes back.

You’re done when…

A healthy model appears in AI studio and a short prompt produces a usable answer.

Removing an engine registration restarts the Hub but does not uninstall the AI app. Schedule that change around active requests and tasks.
