Help / Troubleshooting

A device is missing or offline

Work through discovery, pairing and connection problems.

Before you start

Keep both computers awake and open their own local dashboards. Work through these checks in order.

  1. Check that both Hubs are running

    Open XailonHub on each computer. In the command-line edition, check http://localhost:4747 instead. Closing the desktop app stops its Hub; reopen it to reconnect. A laptop that is asleep or a command-line Hub launched from a closed terminal may also be offline. Wake it and allow a few seconds for reconnection.

  2. Check the network

    Make sure the devices share a reachable network. Guest Wi-Fi, client isolation and some VPNs block connections between computers. Use a network that permits device-to-device traffic.

  3. Try the address if discovery fails

    For a new device, keep Add a device open on the existing Hub. In the joining wizard, type the Hub’s displayed address with port 4748 and enter its fresh code. Discovery uses UDP 4749; direct peer connections use TCP 4748. Allow the Hub app through the firewall rather than turning the firewall off.

  4. Replace an expired or rejected code

    Close the existing pairing window and open Add a device again. Use its current code on the joining computer. Codes expire and cannot be reused after a successful join; repeated incorrect guesses close the pairing window.

  5. Check macOS local network access

    If macOS offers a local-network prompt, allow access for the Hub. If the app is listed in System Settings → Privacy & Security → Local Network, enable it. If no entry or prompt exists, do not keep searching for one: run the Hub from an active Terminal or SSH terminal session and retry. This is a diagnostic workaround, not a persistent installation.

  6. Check previous removal or key changes

    Look under Removed devices and restore the device if appropriate. A device that missed a cluster-key rotation must pair again. If it still fails, note the device names, versions, addresses and the error in Details before asking your administrator for help.

You’re done when…

The device reappears online. An already-paired device normally reconnects automatically once reachable.

Across separate sites, Settings → Connect from anywhere offers Xailon Relay. This is a separate connectivity choice, not a requirement for devices on the same reachable LAN.
