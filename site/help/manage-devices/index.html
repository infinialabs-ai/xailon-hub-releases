Manage sharing and device roles

Pause sharing, rename a computer, remove it or restore it.

Before you start

Choose the device carefully. Role changes affect whether others can use its engines and assistants.

  1. Find the right card

    Open My devices and match the name and hardware. Expand Details to verify its address when names are similar. The current computer is labeled this device.

  2. Pause sharing with Observer

    Select Observer on that card, read the confirmation and select Change role. The device remains connected and can use the Hub, but it stops offering AI work to others.

  3. Resume sharing with Worker

    Select Worker and confirm Change role to share that device’s engines and assistant pools again. Select Hub when you want it to serve as a preferred entry point for the workspace.

  4. Rename a computer

    Open that computer’s own dashboard, go to Settings → This device, edit its name and select Save. The new name will appear on the other dashboards after they refresh.

  5. Remove or restore a device

    Use the trash button on a remote device card to remove it and confirm the action. It appears under Removed devices. Select Restore there to allow it back; it must be running and reachable to reappear.

You’re done when…

The card reflects the selected role or name, or the removed computer appears in Removed devices.

For permanent revocation, Settings offers cluster-key rotation. It restarts online devices and requires offline devices to pair again; plan this with your team. Removing a card does not uninstall the remote app.
