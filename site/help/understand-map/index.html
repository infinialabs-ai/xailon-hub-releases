Help / Everyday use

Read your network and activity

Understand the animated map, health cards and request history.

Before you start

Open Home after your Hub is running. Example screenshots show simulated devices, not your own network.

  1. Explore a device

    Select a computer in the map with a mouse, or focus it with Tab and press Enter. The selection panel shows its name and available models. Select View device for hardware, status and role details.

  2. Filter or pause the map

    Use Everything, Devices or Cloud to focus the map. Use the pause button to stop animated traffic; data continues to refresh. The dotted paths indicate offline devices or optional cloud connections, not proof that a request used them.

  3. Understand a request’s journey

    Below the map, select the numbered walkthrough steps or Play walkthrough. This explains routing; it does not send a prompt. Actual request animations appear when your Hub observes requests.

  4. Check a computer’s health

    Open My devices for processor, graphics and memory gauges. Expand Details for the processor, address, version and last error. A dash means a metric is unavailable; it does not mean zero usage. Illustrations represent hardware families when the exact model is unknown.

  5. Confirm where work ran

    Open Activity. Live requests lists the model, serving device, result, first-token latency and attempts. Use this record and the chat’s Ran on label to confirm a real route. Statistics are scoped to the Hub you are viewing; they are not a permanent audit log.

You’re done when…

You can identify the serving device and distinguish an online machine from an unavailable one.

The walkthrough is educational. Home activity counts cover the running Hub session, and Activity keeps recent routing metadata rather than prompt bodies.
