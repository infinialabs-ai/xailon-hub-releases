XailonHub / Trust

Clear boundaries.
Informed choices.

XailonHub connects your AI tools and devices. These are the protections built in—and the choices that remain yours.

Local administration stays private

The desktop window connects to a random loopback port protected by an ephemeral HttpOnly session cookie. A one-use launch ticket travels through a private process pipe. The regular inference listener does not expose administration routes in desktop mode.

A limited native interface

The web interface has no granted native shell or filesystem commands. External navigation, popups, downloads and developer tools are disabled. The bundled backend is verified before launch. This is not an operating-system sandbox: configured agents and AI engines retain their own access and permissions.

Your network and routing policy

Paired Hubs use authenticated encrypted peer connections. Cloud and relay are off in new configurations. Enabling cloud routing changes where requests may go; review the privacy controls before using sensitive information. Local inference authentication follows your gateway settings.

Portal privacy

This portal uses no analytics scripts, advertising cookies or login. Fonts, illustrations and help are served from this site. Cloudflare processes normal web requests to deliver it, and GitHub handles release downloads. Neither service receives your AI prompts through this portal.

Release status

The first desktop release is a public preview. macOS builds are ad-hoc signed, not notarized. Windows builds are unsigned. Linux uses the system WebKitGTK runtime. Keep your OS and webview up to date. Checksums verify file integrity; they do not replace a trusted publisher signature.

Linux dependency review

The GLib 0.18.5 iterator fix from upstream PR #1343 is backported for RUSTSEC-2024-0429. Some Linux transitive dependencies have unmaintained-package notices; these are tracked in the release security notes. Public packages include third-party notices and the patched library source.

Report a security issue

Please report vulnerabilities privately to hello@infinialabs.ai with the subject “XailonHub security”. Avoid including credentials or private prompts in public issues.
