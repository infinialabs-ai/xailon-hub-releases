Running a server or prefer the command line?

The CLI edition runs the same Hub with a browser dashboard. This command installs the CLI, not the desktop app.

curl -fsSL https://xailonhub.infinialabs.ai/install.sh | sh

On Windows, use the PowerShell installer in the installation guide ↗. Inspect scripts before running them.

Your workspace. Your choices.

Local first, by design.

Private administration.

The desktop app uses its own authenticated local session. The normal API port exposes inference, not the admin console.

Connected, with boundaries.

Paired computers communicate over encrypted connections. Cloud routing and relay connections are optional and off for new setups.

Clear, inspectable releases.

Downloads, checksums, release notes and security information live in a public repository. Know what you’re installing.
